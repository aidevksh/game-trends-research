# Game Trends Research

2026년 10월 13일 기준, 로블록스 해외·한국 인기와 메이플스토리 월드를 비교한 한국어 리서치입니다.

**[HTML 보고서](docs/index.html)** 를 내려받아 브라우저로 열면 검색·시장/장르 필터·과금 근거 필터·인쇄/PDF 저장을 사용할 수 있습니다. 외부 라이브러리·이미지·CDN 없이 작동합니다. GitHub의 파일 화면에서는 HTML 소스가 표시됩니다.

## 조사 범위

7개 카테고리 × 10개, **70개 분석 항목 / 고유 게임 63개**입니다. 해외·국내 중복 7개는 서로 다른 인기 근거로 분석했습니다.

| 시장 | 카테고리 | 항목 |
| --- | --- | ---: |
| 로블록스 해외 | 수집·성장·제작 | 10 |
| 로블록스 해외 | 전투·팀 전략·스포츠 | 10 |
| 로블록스 해외 | 소셜·협동·라운드 체험 | 10 |
| 로블록스 국내 | 실력 경쟁·스포츠·오비 | 10 |
| 로블록스 국내 | 협동·추격·공포 생존 | 10 |
| 메이플스토리 월드 | 클래식·수집·지속 성장 | 10 |
| 메이플스토리 월드 | 한 판 전략·아케이드·시뮬레이션 | 10 |

게임별 설명·특징·인기 요소·과금 탐색·출처, 카테고리별/전체 공통점, 카테고리별 바이브코딩 아이디어 **18개**, 첫 제작 우선 후보 **3개**와 MVP 범위를 포함합니다.

## 선정 기준

- 해외는 Roblox의 글로벌 인기 경험입니다. 해외 국적 이용자만 분리한 통계는 아닙니다.
- 국내는 한국에서 인기 근거가 확인된 게임입니다. 공식 대한민국/컴퓨터 차트의 개별 타이틀 노출과 2025 Replay의 한국 검색어를 사용했고, 관측 기간과 차트 구간을 구분했습니다.
- 메이플스토리 월드는 한국 카탈로그에서 선정한 대표작입니다. 공식 누적 이용자 지표는 전 지역 합산이며, 업데이트 중단 후 플레이가 유지되는 작품은 운영 상태를 표시했습니다.
- **Top 10은 연구자 선정 목록**입니다. 전체 장르를 전수조사한 공식 순위가 아닙니다. 선정 이유와 목록 내부 순서의 기준은 각 카테고리에 표시했습니다.
- 실제 공개 상품·판매 표시·API 기준 가격과 미확인 인게임 상점을 구분했습니다. 지역·계정별 최종 결제 가격은 다를 수 있습니다. 빈 상점이 무료 게임을 뜻하지 않습니다.
- 인기 요소와 추천은 질적 설계 분석입니다. 동접·누적 방문·누적 이용자를 서로 동일한 지표로 비교하지 않았습니다. 제작 기간은 1인·AI 보조·기본 엔진 경험·주 약 20시간의 작은 MVP 추정입니다.

각 게임의 출처는 HTML 카드에서 펼쳐 볼 수 있습니다. 스냅샷에는 공개 사실·숫자·상품명·확인 경로를 보존하고 장문 원문과 불필요한 식별 정보를 제외했습니다.

## 파일과 재생성

| 경로 | 내용 |
| --- | --- |
| `docs/index.html` | 인터넷 없이 읽을 수 있는 HTML 보고서 |
| `docs/report-data.json` | 보고서의 전체 정리 데이터 |
| `research/roblox-global.json` | 해외 30개 분석 |
| `research/roblox-korea.json` | 한국 인기 20개 분석 |
| `research/maple-worlds.json` | 메이플 월드 20개 분석 |
| `research/overview.json` | 종합 분석과 첫 제작 추천 |
| `research/*snapshot.json`, `research/korea-api-evidence.json` | 공개 인기·상품 근거 스냅샷 |
| `scripts/build_report.py` | 정리 데이터를 HTML로 생성 |
| `scripts/report-template.html` | 보고서 레이아웃·상호작용 |
| `scripts/validate_report.py` | 항목 수·중복·필수 정보·출처·내부 링크·오프라인 자산 검증 |

Python 3.10 이상이면 추가 패키지 없이 보고서를 재생성할 수 있습니다. 이 명령은 최신 게임 지표를 재수집하지 않고, 보존된 조사 데이터를 사용합니다.

```sh
python scripts/build_report.py
python scripts/validate_report.py
```

수정 시 `research/*.json`의 관련 분석 데이터와 출처·조회일을 함께 바꾸고 보고서를 재생성합니다.

데스크톱(1440px)·모바일(390px) 화면을 확인했고 시장/카테고리 필터, 검색, 빈 결과, 초기화, 과금 근거 필터, 인쇄 전체 항목, JavaScript 오류 및 가로 넘침을 검증했습니다.
