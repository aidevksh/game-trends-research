## 선정 기준

- 해외는 Roblox의 글로벌 인기 경험입니다. 해외 국적 이용자만 분리한 통계는 아닙니다.
- 국내는 한국에서 인기 근거가 확인된 게임입니다. 공식 대한민국/컴퓨터 차트의 개별 타이틀 노출과 2025 Replay의 한국 검색어를 사용했고, 관측 기간과 차트 구간을 구분했습니다.
- 메이플스토리 월드는 한국 카탈로그에서 선정한 대표작입니다. 공식 누적 이용자 지표는 전 지역 합산이며, 업데이트 중단 후 플레이가 유지되는 작품은 운영 상태를 표시했습니다.
- Minecraft 서버 게임은 공식 운영자의 개별 모드 자료, 월드는 공식/제작자 상품 소개, 성장·생존 확장은 제작자 배포 자료를 근거로 선정했습니다. 서버 공통 상품을 개별 모드 전용 BM으로 표시하지 않았습니다.
- 스타1은 SEN의 **대표·보존 배포본**, 스타2는 제작자 자료와 확인 가능한 활동 사례, 워크3는 Hive 등의 현재 갱신작과 역사적 대표작을 함께 조사했습니다. 최신 한국 유즈맵 인기 순위로 해석하지 않습니다.
- **Top 10 / 대표 10선은 연구자 선정 목록**입니다. 전체 장르를 전수조사한 공식 순위가 아닙니다. 선정 이유와 목록 내부 순서의 기준은 각 카테고리에 표시했습니다.
- 실제 공개 상품·판매 표시·API 기준 가격과 미확인 인게임 상점을 구분했습니다. 과거 가격·공식 출시·누적 다운로드를 현재 판매·동접·매출로 바꾸지 않았습니다. 지역·계정별 최종 결제 가격은 다를 수 있습니다.
- 인게임 광물·골드·카드·유닛 구매를 실제 현금 과금의 증거로 사용하지 않았습니다. 블리자드의 승인 프리미엄 사례·개발 후원과 일반 판매 허용도 구분했습니다.
- 인기 요소와 추천은 질적 설계 분석입니다. 동접·누적 방문·누적 이용자·누적 다운로드를 동일한 지표로 비교하지 않았습니다. 제작 기간은 1인·AI 보조·기본 엔진 경험·주 약 20시간의 작은 MVP 추정입니다.
- 원본 플랫폼 안의 프로토타입과 자체 코드·아트로 만드는 독립 신작의 구현·수익화 범위를 구분했습니다. 조사 대상 게임·맵 파일을 직접 실행하거나 결제한 것은 아닙니다.

각 게임의 출처는 HTML 카드에서 펼쳐 볼 수 있습니다. 스냅샷에는 공개 사실·숫자·상품명·확인 경로를 보존하고 장문 원문과 불필요한 식별 정보를 제외했습니다.

Python 3.10 이상이면 추가 패키지 없이 보고서를 재생성할 수 있습니다. 이 명령은 최신 게임 지표를 재수집하지 않고, 보존된 조사 데이터를 사용합니다.

```sh
python scripts/build_report.py
python scripts/validate_report.py
```

수정 시 `research/*.json`의 관련 분석 데이터와 출처·조회일을 함께 바꾸고 보고서를 재생성합니다. 새 조사 대상은 `research/markets.json`에 파일·기대 카테고리/항목 수를 등록합니다.

데스크톱(1440px)·모바일(390px) 화면, 모든 조사 대상의 시장/카테고리 필터, 검색, 빈 결과, 초기화, 과금 근거 필터, 필터 적용 중 인쇄의 전체 항목, JavaScript 오류 및 가로 넘침을 검증했습니다.
